# Images

Drop site photos here. Suggested assets:

- `hero.jpg` — hero background (river/willow/mountains, 2000px wide)
- `artist-photo.jpg` — main artist photo (3:4 portrait, ~1200px wide)
- `artist-photo-wide.jpg` — landscape crop for press use
- `logo.svg` or `logo.png` — artist logo (SVG preferred)
- `favicon.ico` — 32x32 site favicon
- `og-image.jpg` — social sharing image (1200x630)

After adding, reference them in the HTML files — e.g., replace `<div class="about__image">...</div>` with `<img src="images/artist-photo.jpg" alt="Jeffrey River" />`.
